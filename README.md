## Install
On a Switch running custom firmware, unzip and copy the `switch` folder to the root of the SD card
(you get `switch/iwbtgrt/iwbtgrt.nro`), then launch it from the Homebrew Menu. Title-override mode (hold R while starting
a game) is recommended so the game gets the full memory; applet mode (Album) also works.
Saves go to `sdmc:/switch/iwbtgrt/save`. The NSP (title ID `01005666A1B70000`) is for emulators or installing to NAND.

## What's in it
- Tribute mode, playable as the Tribute Kid
- Boss Rush modes once unlocked, each with its own best time
- File select with a picture of each save, New Game on empty slots
- 16 languages, with some Brazilian Portuguese voice acting
- Joy-Con, Pro Controller and handheld mode, remappable controls

## Controls
| Switch | Action |
| --- | --- |
| D-pad / left stick | Move |
| B | Jump |
| Y | Shoot |
| X | Restart |
| + | Pause |
| R | Skip |
| A | Back |

Controls can be remapped in *Options*.
